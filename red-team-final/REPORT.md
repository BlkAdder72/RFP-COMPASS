## 1. High priority: required-event protection breaks across normal source anchors

**Reproduction:** the source contains:

```text
S001 | RFP p. 3 line 10 | Mandatory bidder events:
S002 | RFP p. 3 line 11 | Our holiday potluck is January 12, 2027, at 1:30 PM.
```

An evaluator-built defective card keeps the heading in Section 4 but wrongly puts S002 only in Section 12. The original warns that Section 6 is missing S002. The updated rebuild prints its personal filter note and no warning for S002. Both return structural PASS, which cannot resolve the semantic error.

The same content with **identical anchors** correctly produces the warning in both versions. Different line anchors and different paragraph anchors both reproduce the regression. This isolates the failure to citation granularity rather than a changed activity/date. Distinct anchors are normal in the input contract and packet builder, not an invalid adversarial format.

**Cause:** rebuild/tools/validate_packet.py:77–83 stores the literal header anchor in protected_anchors, then protects the following statement only if its anchor is exactly equal. The actual requirement is supplied by a preceding procurement heading; citation equality is not a reliable document-scope relationship.

**Why this could cost the win:** the judges explicitly try to break the clone and value closing a gap without damaging working safeguards. This is another case where the rebuild can hide a real missing-event warning that the original produces. It is not proof that the translator itself will misroute this event; it proves the validator safety net weakens if that routing error occurs. The source cards here were built by the evaluator, not generated by the model.

**Recommendation:** protect requirement-bearing context across legitimate line/paragraph anchors and explicit scope boundaries. Test normal builder-generated anchors, adjacent headings and attachment transitions, not just one repeated anchor. Preserve these failing records and require both default Q8 and these controls to pass. Do not solve this by dropping all filtering or merely adding more personal keywords.

Evidence: evidence/required-event-same-anchor/, required-event-different-lines/ and required-event-different-paragraphs/; exact source/card files in inputs/.
